APPENDIX: Common Issues & Quick Fixes
================================================================================

ISSUE: "Token verification failed"
FIX: 1) Verify SECRET_KEY matches in .env
     2) Restart API service
     3) Generate fresh token

ISSUE: "CORS error after deployment"
FIX: 1) Check ALLOW_ORIGINS in .env (includes your domain?)
     2) Restart API service
     3) Clear browser cache

ISSUE: "Database migration failed with constraint error"
FIX: 1) Restore from backup
     2) Check for duplicate (family_id, elder_id) pairs
     3) Clean data and re-run migration

ISSUE: "Webhook returns 401 Unauthorized"
FIX: 1) Verify HOME_ASSISTANT_WEBHOOK_SECRET matches
     2) Check HA is computing correct SHA256
     3) Verify request body encoding

ISSUE: "API won't start after deployment"
FIX: 1) Check PyJWT is installed: pip show PyJWT
     2) Verify SECRET_KEY/API_KEY in .env
     3) Check logs: docker logs elderly-care-api
     4) Restore previous code version if needed
